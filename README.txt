КАТАЛОГ ОПТОВЫХ ЦЕН — v15 (с накладными)

СОСТАВ АРХИВА
  index.html            — приложение целиком (каталог из Prays_17: 42 категории, 3333 товара)
  sw.js, service-worker.js — сервис-воркер, кеш catalog-v15
  manifest.webmanifest  — манифест PWA
  icon-192.png, icon-512.png — иконки
  README.txt            — этот файл (в репозиторий не загружать)

ЗАГРУЗКА В РЕПОЗИТОРИЙ
  1. Загрузите все файлы, кроме README.txt, в корень репозитория.
  2. Старые index.html, sw.js, service-worker.js ЗАМЕНИТЕ (не дублируйте).
  3. Commit, дождитесь зелёной галочки Actions.
  4. На телефоне полностью закройте браузер (смахните из недавних) и откройте каталог заново.

ЧТО НОВОГО В v15
  * Кнопка «Заявки» открывает настоящий экран со списком накладных.
  * При оформлении корзины создаётся накладная по образцу:
    «Реализация товаров № N от ДД.ММ.ГГГГ», Поставщик, Покупатель,
    таблица №/Товар/Кол-во/Ед./Цена/Сумма, Итого, «В том числе НДС: 0»,
    «Всего наименований…», сумма прописью, Отпустил/Получил.
  * Кнопка «Открыть накладную» в списке заявок показывает документ по образцу.
  * «✏️ Редактировать» — правятся реквизиты, названия, количество, единицы (шт/кг),
    цены; всё пересчитывается и сохраняется.
  * Экспорт: 🖨 Печать/PDF, ⬇ Скачать (HTML), ✉ Email, ↗ Поделиться (WhatsApp/Telegram),
    📊 Экспорт для 1С (XML CommerceML — загружается обработкой «Загрузка документов из файла»).
  * Настройки (кнопка ⚙️): Поставщик, Покупатель, ФИО «Отпустил», следующий номер накладной
    (номер автоматически увеличивается после каждой заявки).
  * Заявки и корзина хранятся локально, старые данные (ключи katalog_…/catalog_…) подхватываются.
